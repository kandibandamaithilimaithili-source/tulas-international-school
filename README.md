# Tulas International School Homepage

A modern and responsive homepage redesign for Tulas International School.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS

## Features

- Responsive design
- School campus hero image
- Dark / Light theme
- Scroll-triggered animations
- Scroll progress bar
- Smooth navigation
- Modern UI design

## How to Run the Project

1. Clone or download the project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

npm install

5. Start the development server:

npm run dev

6. Open the localhost link shown in the terminal.
